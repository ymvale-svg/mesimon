כניסה עם חשבון Google

כ-15 דקות · חינם · פעם אחת בלבד
מה זה נותן: במקום לזכור סיסמה נפרדת, מי שיש לו חשבון Google לוחץ כפתור אחד ונכנס. מה זה לא נותן: חשבון Google אינו יוצר משתמש חדש. הכניסה מותרת אך ורק לכתובת שכבר רשומה במערכת כמשתמש או כספק פעיל — אחרת כל אדם בעולם עם חשבון Google היה נכנס. אתה קודם מוסיף את האדם למערכת, ורק אז הוא יכול להיכנס עם Google.

שלב 1 — פרויקט ב-Google Cloud

  1. נכנסים ל־console.cloud.google.com עם חשבון Google שלך.
  2. למעלה, ליד הלוגו, יש בוחר פרויקטים. לוחצים עליו ואז New Project.
  3. שם הפרויקט: MESIMON. לוחצים Create וממתינים כמה שניות.
  4. לוודא שהפרויקט החדש נבחר בבוחר שלמעלה לפני שממשיכים — זו טעות נפוצה, ואז ההגדרות נכנסות לפרויקט אחר.

שלב 2 — מסך ההסכמה

זה המסך שהמשתמש רואה כשהוא מאשר את הכניסה. חובה להגדיר אותו לפני יצירת המפתחות.

  1. בתפריט הצד: APIs & Services ← OAuth consent screen.
  2. סוג: External ← Create.
  3. ממלאים:
    App name: MESIMON
    User support email: המייל שלך
    Developer contact information: אותו מייל
    את הלוגו והדומיינים אפשר להשאיר ריקים.
  4. Scopes — לא נוגעים בכלום. המערכת מבקשת רק שם ואימייל, וזה נכלל בברירת המחדל.
  5. שומרים עד הסוף.
חשוב — Publishing status. אחרי היצירה המסך במצב Testing, ואז רק כתובות שתוסיף ידנית כ-Test users יכולות להיכנס, וההרשאה פגה כל 7 ימים. לוחצים Publish app ומאשרים.

זה לא שולח את האפליקציה לבדיקה של Google — בדיקה נדרשת רק להרשאות רגישות, ואנחנו מבקשים שם ואימייל בלבד. הפרסום בטוח, כי בכל מקרה נכנסת רק כתובת שרשומה במערכת.

שלב 3 — יצירת המפתחות

  1. APIs & Services ← Credentials ← Create Credentials ← OAuth client ID.
  2. Application type: Web application. Name: MESIMON Web.
  3. גוללים ל־Authorized redirect URIs ולוחצים ADD URI לכל אחת מאלה:
    https://mesimon.onrender.com/api/auth/google/callback
    https://mesimon.co.il/api/auth/google/callback
    http://localhost:3000/api/auth/google/callback
    להוסיף את שלושתן עכשיו — כך המעבר לדומיין החדש לא ישבור את הכניסה, והבדיקה המקומית תמשיך לעבוד.
  4. לוחצים Create. נפתח חלון עם Client ID ו-Client Secret.
אל תשלח לי את ה-Client Secret ואל תשמור אותו בקובץ. מדביקים ישר ב-Render. אם נחשף — מוחקים את ה-Client ב-Google ומייצרים חדש.

שלב 4 — מזינים ב-Render

בשירות mesimon ← Environment:

KeyValue
GOOGLE_CLIENT_IDה-Client ID (מסתיים ב-.apps.googleusercontent.com)
GOOGLE_CLIENT_SECRETה-Client Secret

Save. Render מפרסם מחדש, ובמסך הכניסה יופיע הכפתור "כניסה עם חשבון Google". כל עוד שני המשתנים אינם מוגדרים — הכפתור פשוט לא מוצג, והכניסה עם סיסמה עובדת כרגיל.

שלב 5 — בודקים

  1. נכנסים למערכת ומוודאים שהכתובת שאתה מתכוון להיכנס בה (ymvale@gmail.com) רשומה כמשתמש פעיל.
  2. יוצאים מהמערכת, ובמסך הכניסה לוחצים "כניסה עם חשבון Google".
  3. בוחרים חשבון ומאשרים. אמור לחזור למערכת מחובר.
