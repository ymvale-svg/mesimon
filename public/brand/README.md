# הלוגו של משימון — ערכת המותג

כל הקבצים כאן נוצרו מאותה הגדרה גאומטרית אחת (`tools/brand/build-logo.py`).
ה-SVG הוא המקור; ה-PNG נגזר ממנו. אין להעתיק לוגו מצילום מסך.

## מה לקחת, מתי

| שימוש | קובץ |
| --- | --- |
| אתר, מצגת, מסמך — רקע בהיר | `svg/mesimon-logo-horizontal.svg` |
| רקע כהה או צילום | `svg/mesimon-logo-horizontal-white.svg` |
| כשיש מקום לכיתוב | `svg/mesimon-logo-horizontal-tagline.svg` |
| פריסה צרה, כריכה, שלט | `svg/mesimon-logo-stacked.svg` |
| סמל בלבד (אווטאר, אפליקציה, חותמת) | `svg/mesimon-mark.svg` |
| סמל ללא אריח, על רקע נקי | `svg/mesimon-symbol.svg` (ולבן / שחור) |
| סמל אפליקציה, ריבוע מלא (iOS/אנדרואיד) | `svg/mesimon-icon.svg` |
| פאביקון 32 ומטה | `svg/mesimon-icon-compact.svg` |
| שיתוף ברשתות / Open Graph | `png/mesimon-social-1200x630.png` |
| תמונת פרופיל (וואטסאפ, Google) | `png/mesimon-avatar-640.png` |

PNG: `@2x` הוא הגרסה הצפופה. לדפוס — להשתמש ב-SVG.

## הגופן

הכיתוב הוא **Assistant** במשקל 800 (השם) ו-600 (הכיתוב מתחתיו), והאותיות
הומרו לצורות — אין תלות בגופן מותקן.

## הצורה

שני הלוחות המוטים הם צורת הלוחות שבלוגו של **אשל הירדן**: פאה בהירה ופאה
מלאה שנפגשות בקו אמצעי, כמו קופסה שרואים מהפינה. זה הקשר בין המוצר לחברה.
הווי שמתחתם הוא המשימה שנסגרה. הגאומטריה זהה לזו שב-`public/js/ui.js`
(`UI.logoMark`), ב-`tools/make-icons.js` ובפאביקון שב-`index.html` — שינוי
באחד מחייב שינוי בכולם.

## כללי שימוש

* **שטח נשימה** — לפחות גובה של חצי מהסמל מכל צד.
* **גודל מזערי** — לוגו אופקי: 96 פיקסל רוחב. סמל בלבד: 24 פיקסל. מתחת
  ל-32 פיקסל להשתמש ב-`mesimon-icon-compact.svg` (הווי בלבד).
* **אין** למתוח, לסובב, להחליף צבעים, להוסיף צל או מסגרת, או לכתוב את השם
  בגופן אחר.
* על רקע עמוס — הגרסה הלבנה, או האריח (`mesimon-mark.svg`).

## בנייה מחדש

```
python3 -m pip install fonttools brotli
python3 tools/brand/build-logo.py public/brand/svg
node    tools/brand/render.js <jobs.json>
```

`build-logo.py` מצפה לקובצי Assistant (`assistant-800.woff2`, `assistant-600.woff2`)
בתיקייה שמעליו; מורידים אותם מ-Google Fonts (רישיון OFL).
