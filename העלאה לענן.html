העלאת MESIMON לענן

מדריך צעד אחר צעד · אשל הירדן
לקרוא לפני שמתחילים.
בענן המערכת חשופה לאינטרנט — כל אחד בעולם שיידע את הכתובת יגיע למסך הכניסה. לכן אסור להעלות לענן כל עוד הסיסמאות הן 1234. הסעיף האחרון במסמך מפרט מה חובה לעשות לפני שמכניסים נתונים אמיתיים.

מה זה עולה ומה מקבלים

נושאפירוט
עלותכ־7 דולר לחודש לשרת, ועוד כדולר לחודש לאחסון. סך הכול כ־30 ש״ח לחודש.
מה מקבליםכתובת קבועה באינטרנט עם HTTPS, זמינה 24/7, בלי מחשב שצריך להישאר דלוק במשרד.
איפה הנתוניםפרנקפורט, גרמניה. זו האפשרות הקרובה ביותר לישראל מבחינת מהירות ורגולציה.
כמה זמןכשעה בפעם הראשונה.

שלב 1 — פותחים חשבון GitHub ומעלים את הקוד

GitHub הוא המקום שבו הקוד יישמר. שירות הענן מושך משם את הקוד בכל עדכון.
  1. נכנסים ל־https://github.com/signup ופותחים חשבון עם אימייל העבודה.
  2. אחרי ההרשמה לוחצים על הכפתור הירוק New ליצירת מאגר חדש.
  3. ממלאים:
    Repository name: mesimon
    ומסמנים Private — חשוב, כדי שהקוד לא יהיה גלוי לכולם.
    לוחצים Create repository.
  4. במסך שנפתח לוחצים על הקישור uploading an existing file.
  5. פותחים את התיקייה P:\תפעול\תפעול כללי\מיחשוב\משימון, בוחרים את כל התוכן שלה (Ctrl+A) וגוררים לחלון הדפדפן.
    לא לגרור את התיקיות data ו־uploads. אלו הנתונים המקומיים שלך; בענן ייווצרו נתונים חדשים משלו. אם הן נגררו בטעות — לוחצים על ה־X שלידן ומסירים.
  6. גוללים למטה ולוחצים Commit changes. ההעלאה לוקחת דקה.

שלב 2 — פותחים חשבון בשירות הענן

  1. נכנסים ל־https://render.com ולוחצים Get Started.
  2. בוחרים Sign in with GitHub — כך השניים מחוברים אוטומטית.
  3. מאשרים ל־Render גישה למאגר mesimon בלבד (לא לכל המאגרים).

שלב 3 — יוצרים את השירות

  1. בלוח הבקרה לוחצים New + ואז Blueprint.
    בוחרים Blueprint ולא Web Service — יש בתיקייה קובץ הגדרות בשם render.yaml שמגדיר הכול מראש: את השרת, את הדיסק לנתונים ואת גרסת התוכנה.
  2. בוחרים את המאגר mesimon ולוחצים Connect.
  3. Render יציג שהוא זיהה שירות בשם mesimon עם דיסק של 5GB. לוחצים Apply.
  4. מחכים. הפעם הראשונה לוקחת 3–5 דקות. כשמופיע Live בירוק — המערכת עלתה.
  5. למעלה במסך מופיעה הכתובת, משהו כמו:
    https://mesimon.onrender.com
    זו הכתובת שתחלק לצוות ולספקים. היא כבר מאובטחת ב־HTTPS.

שלב 4 — חובה לפני שמכניסים נתונים אמיתיים

עד שהצעדים האלה לא בוצעו, אין להזין למערכת שום מידע אמיתי.
  1. להחליף את כל הסיסמאות. נכנסים כמנהל מערכת ← ניהול המערכת ← משתמשים והרשאות, ולכל משתמש קובעים סיסמה חזקה (12 תווים לפחות, לא סיסמה שמשמשת במקום אחר). אותו דבר לכל ספק.
  2. להשבית את משתמשי הדמו. אבי כהן, רונית לוי, דנה שמש, יוסי ברק וכן שני ספקי הדמו — למחוק או להעביר לסטטוס לא פעיל.
  3. להגדיר גיבוי. בתפריט Render של השירות יש Disks ובו אפשרות Snapshot. כדאי להפעיל גיבוי יומי.
  4. לבדוק שהכול עובד — להתחבר, ליצור משימה, להעלות קובץ, לצאת ולהיכנס שוב.

איך מעדכנים את המערכת בהמשך

כשמשנים משהו בקוד: נכנסים למאגר ב־GitHub, לוחצים Add file ← Upload files, גוררים את הקבצים המעודכנים ולוחצים Commit changes. Render מזהה את השינוי ומעלה גרסה חדשה תוך דקות, לבד.

הנתונים לא נמחקים בעדכון. מסד הנתונים והקבצים יושבים על דיסק נפרד שנשאר במקומו בין גרסאות. זה מוגדר מראש בקובץ ההגדרות.

האתר נטען אבל ריק לוודא שהתיקייה public הועלתה ל־GitHub על כל תוכנה.
אי אפשר להתחבר אחרי 10 ניסיונות כושלים הכניסה נחסמת ל־15 דקות מאותו מחשב. להמתין ולנסות שוב.
הנתונים נעלמו אחרי עדכון סימן שהשירות נוצר כ־Web Service ולא כ־Blueprint, ולכן בלי דיסק קבוע. יש למחוק את השירות ולחזור על שלב 3 עם Blueprint.

רוצה כתובת משלך במקום mesimon.onrender.com?

אם יש לחברה דומיין (למשל eshel.co.il), אפשר להצמיד כתובת כמו mesimon.eshel.co.il. זה נעשה בתפריט Settings ← Custom Domain של Render, ודורש הוספת רשומה אחת אצל מי שמנהל את הדומיין של החברה. תהליך של 10 דקות, אבל צריך גישה לניהול הדומיין — כנראה דרך המחשוב.
