# 🎨 עיצוב המודעות — מהסקיל ui-ux-pro-max

מקור: https://github.com/nextlevelbuilder/ui-ux-pro-max-skill (commit `4f2dbb6`), רישיון MIT (`LICENSE-ui-ux-pro-max.md`).
הוכנס למנוע המודעות ב-10.11.2026 (ישראל: "מצרף את הסקיל לעיצוב מודעות — תכניס אותו למנוע שלך").

| קובץ | מה | מאיפה בסקיל |
|---|---|---|
| `palettes.json` | 192 פלטות צבע לפי סוג עסק / אירוע (ראשי, משני, הדגשה, רקע, טקסט, גבול) | `data/colors.csv` |
| `styles.json` | 9 הסגנונות שמתאימים לדפוס (Swiss, Minimal & Direct, Editorial, Bold Typography…) | `data/styles.csv` |

הכללים מהסקיל שהמנוע (`server/ai/notice-design.js`) מיישם: היררכיה בגודל, משקל וריווח; ניגודיות 4.5:1;
ריווח בכפולות של 8; גובה שורה 1.5–1.75 לגוף; עד שני גופנים; הדגשה אחת; רווח לבן מכוון; הדף מלא ומאוזן.

צימודי הגופנים של הסקיל מותאמים לעברית (`server/fonts`, רישיון OFL): **Heebo** (מודרני), **Frank Ruhl Libre**
(אלגנטי, לכותרות), **Rubik** (ידידותי, לאירועים). קבצים סטטיים שנחתכו מהגופנים המשתנים של Google Fonts.
