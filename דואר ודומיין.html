איפה מוסיפים את רשומות ה-DNS — במקרה שלנו

הדומיין mesimon.co.il רשום בפאנל שבו מופיע הכפתור "עריכת Zone", ושרתי ה-DNS שלו הם ns1.sitesdepot.com ו-ns2.sitesdepot.com.

הנקודה הקריטית: רשומות DNS משפיעות רק אם הן נוספות בשרתים שהדומיין מפנה אליהם. אם עורך ה-Zone שבפאנל הרישום מנהל את אותם שרתי sitesdepot — הכול פשוט. אם sitesdepot הוא ספק אחסון נפרד — עריכה בפאנל הרישום לא תעשה כלום, והרשומות צריכות להיכנס בפאנל של sitesdepot.

איך יודעים מי מהשניים

  1. לוחצים על "עריכת Zone" בפאנל הרישום.
  2. אם נפתחת רשימה עם רשומות קיימות (A, MX, CNAME, TXT) — זה המקום הנכון. כאן מוסיפים גם את רשומות הדואר וגם את הרשומה של Render.
  3. אם המסך ריק, או כתוב בו שהדומיין מנוהל בשרתי DNS חיצוניים — צריך להיכנס לפאנל של sitesdepot ולהוסיף שם. אם אין לך גישה אליו, זו פנייה למי שהקים את האחסון.

בכל מקרה — אותו מקום משמש לשני הדברים: רשומות ה-SPF/DKIM של הדואר, והרשומה שתצמיד את mesimon.co.il לאתר ב-Render. אין צורך בשני פאנלים שונים.

שלב 2 — לאמת את הדומיין אצל הספק

אחרי ההרשמה, הספק יבקש לאמת שאתה בעל mesimon.co.il, וייתן לך רשומות DNS להוסיף. זה מה שהוא ייתן — הערכים המדויקים מגיעים ממנו, לא מכאן:

סוגלמה זה
TXT (SPF)מצהיר אילו שרתים מורשים לשלוח בשם הדומיין. בלעדיו — ספאם.
TXT או CNAME (DKIM)חתימה דיגיטלית על כל מייל, שמוכיחה שהוא לא זויף.
TXT (DMARC)אומר לג׳ימייל מה לעשות עם מייל שנכשל בשתי הבדיקות. לא חובה אבל מומלץ.
את הרשומות מוסיפים אצל מי שמנהל את הדומיין mesimon.co.il — החברה שקנית ממנה אותו. אם המחשוב מנהל את זה, זה התהליך שצריך להעביר להם: העתקה של 2–3 שורות ללוח ה-DNS. האימות אצל הספק לוקח מדקות עד כמה שעות עד שהרשומות מתפשטות.

איפה בדיוק מוצאים את פרטי ה-SMTP

הפרטים לא קיימים לפני שיש חשבון — הם נוצרים בשבילך אצל הספק. אלה המסלולים המדויקים:

Resend — המסלול הקצר

  1. נכנסים ל־resend.com ופותחים חשבון.
  2. Domains ← Add Domain, מזינים mesimon.co.il. המסך יציג את רשומות ה-DNS להוסיף. מוסיפים אותן אצל מנהל הדומיין ומחכים שיהיה כתוב Verified.
  3. API Keys ← Create API Key. המפתח מוצג פעם אחת בלבד ומתחיל ב־re_. מעתיקים אותו ישר לתוך Render — לא שומרים אותו בקובץ ולא שולחים אותו לאף אחד.
  4. הערכים ל-Render:
    SMTP_HOST = smtp.resend.com
    SMTP_PORT = 587
    SMTP_USER = resend ← בדיוק המילה הזו, זה לא שם המשתמש שלך
    SMTP_PASS = המפתח שמתחיל ב־re_

Brevo — אלטרנטיבה

  1. brevo.com ← הרשמה.
  2. Senders, Domains & Dedicated IPs ← Domains ← מוסיפים ומאמתים את mesimon.co.il לפי הרשומות שיוצגו.
  3. בתפריט החשבון (למעלה מימין) ← SMTP & API ← לשונית SMTP. כאן מופיעים כל הפרטים במסך אחד: השרת, הפורט, ה-Login ומפתח ה-SMTP.
  4. הערכים ל-Render:
    SMTP_HOST = smtp-relay.brevo.com
    SMTP_PORT = 587
    SMTP_USER = ה-Login שמוצג באותו מסך
    SMTP_PASS = מפתח ה-SMTP שמוצג באותו מסך
שמות המסכים אצל הספקים משתנים מדי פעם. העוגן שלא משתנה: מחפשים בממשק "SMTP" או "SMTP credentials" — שם תמיד יופיעו ארבעת הפרטים. אם מסך כלשהו נראה אחרת ממה שכתוב כאן, תשלח לי צילום ואכוון.
אל תשלח לי את המפתח. אני לא צריך לראות אותו ואין לי מה לעשות איתו — אתה מדביק אותו ישירות ב-Render. אם המפתח נחשף בטעות, מוחקים אותו אצל הספק ומייצרים חדש.

שלב 3 — להזין את הפרטים ב-Render

הספק ייתן לך פרטי SMTP. נכנסים לשירות ב-Render ← Environment, ומוסיפים:

KeyValue
SMTP_HOSTמה שהספק נתן (למשל smtp.resend.com)
SMTP_PORT587
SMTP_USERשם המשתמש מהספק
SMTP_PASSהמפתח / הסיסמה מהספק
SMTP_FROMnoreply@mesimon.co.il ← זו הכתובת שתופיע כשולח
SMTP_FROM_NAMEMESIMON (אופציונלי — שם התצוגה ליד הכתובת)

שומרים. Render מפרסם מחדש לבד, וזה הכול — כל ההזמנות והתזכורות ייצאו מהכתובת הזו.

בדיקה: ניהול המערכת ← משתמשים והרשאות ← לוחצים "✉ הזמנה" ליד עצמך. אם הגיע מייל מ־noreply@mesimon.co.il — סיימנו. אם לא, הלוג ב-Render יראה בדיוק מה שרת הדואר החזיר.

ובזמן שאתה שם — האתר עצמו על הדומיין

קנית דומיין, אז שווה שהמערכת תשב עליו במקום על הכתובת של Render:

  1. ב-Render: Settings ← Custom Domain ← Add, ומזינים mesimon.co.il (ואם רוצים גם www.mesimon.co.il).
  2. Render ייתן רשומה אחת להוסיף ב-DNS. מוסיפים אותה אצל מנהל הדומיין.
  3. Render מנפיק תעודת HTTPS אוטומטית. תוך דקות עד שעה הכתובת עולה.
  4. חשוב: להוסיף משתנה סביבה PUBLIC_URL = https://mesimon.co.il. בלעדיו קישורי ההזמנות במיילים ימשיכו להצביע לכתובת של Render.
אם הגדרת כניסה עם Google — הדומיין החדש חייב להתווסף גם שם, ב-Google Cloud Console, כ-Authorized redirect URI: https://mesimon.co.il/api/auth/google/callback. אחרת הכניסה עם Google תישבר ברגע שתעבור לדומיין.
